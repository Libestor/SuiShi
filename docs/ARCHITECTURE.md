# 架构设计

## 1. 设计目标

系统优先保证资产历史可追溯、动态分配可解释、外部数据接入灵活，以及手机查看与电脑管理都顺手。第一版固定三个篮子，避免为了通用性牺牲投资场景的完整语义。

## 2. 组件

```text
Browser
  │
  ▼
Nginx :8080
  ├── /        → Vinext / React frontend :3000
  └── /api     → FastAPI backend :8000
                         │
             ┌───────────┼────────────┐
             ▼           ▼            ▼
          MySQL       Scheduler    Python Runner
       durable data   hourly jobs   isolated process
                                      │
                                      ▼
                              external data APIs
```

### 前端

- Vinext、React 19、TypeScript 与普通 CSS。
- 手机端强调资产树、目标进度、成就和通知。
- 电脑端补充资产、流水、数据源与规则管理入口。
- 数据源以脚本库管理，一条记录包含 Python 代码、依赖、资产绑定、输入/输出映射和调度周期。
- 平台设置聚合流入分配、应急目标和 Webhook 连接，不占用总览视觉空间。
- 所有权威数据来自后端，浏览器存储仅用于视图偏好。

### 后端

- Python 3.12、FastAPI、SQLAlchemy 与 Alembic。
- 提供资产、估值、流水、目标、动态分配、数据源和通知 API。
- 登录时在服务器端校验平台 Token，成功后签发有限时的 `HttpOnly` 会话 Cookie；命令行仍可使用 Token Header。
- 后台调度器定期保存估值快照并运行到期数据源。

### 数据库

- MySQL 8.4。
- 业务记录不物理删除，统一使用 `deleted_at` 软删除。
- 流水和估值采用追加式历史记录；异常记录标记无效，不覆盖历史。
- Alembic 迁移前运行数据库备份脚本。

### Python Runner

- 与后端分离的 Docker 服务，不直接连接业务数据库。
- 接收脚本、输入字典、依赖列表和执行超时。
- 每组依赖使用 `uv` 创建可缓存的独立虚拟环境，降低包版本冲突。
- 脚本只能通过返回字典影响业务数据，后端负责字段映射和校验。
- 批量执行时以稳定的资产键完成输入与输出匹配。

## 3. 核心数据规则

### 资产价值

```text
原币价值 = 持有份额 × 当前单价
人民币价值 = 原币价值 × 最新汇率
篮子价值 = 资产人民币价值之和 + 篮子等待购买现金
```

无法拆分份额和单价的产品使用 `份额 = 1`、`单价 = 当前总余额`。

成长与高风险之间的风险比例只使用已购买产品的最新已知价值，等待购买现金不参与该比例，也不参与动态分配的低配判断；现金仍计入篮子总额与总资产。

### 新资金分配

1. 先计算应急储备金缺口。
2. 新资金优先补足缺口。
3. 剩余资金进入成长与高风险篮子。
4. 固定模式按设定比例分配。
5. 动态模式仅根据两个篮子的已投资产品价值计算缺口，优先补低配篮子；等待购买现金不参与，不自动卖出资产。

### 历史与删除

- 配置数据允许修改并写审计日志。
- 已确认流水不原地重写；修正使用冲正或替代记录。
- 历史估值不物理删除；错误数据设置为无效。
- 所有实体删除均写 `deleted_at`，默认查询自动排除。

## 4. 调度和通知

- 默认每 60 分钟保存估值快照，支持手动触发。
- 数据源拥有独立的分钟级执行周期。
- Webhook 通知由事件触发，并按滚动时间窗口执行“最多 N 次”限流。
- 条件持续成立不会为了凑满次数而主动制造重复消息。
- 里程碑正式解锁永久只记录和推送一次。

## 5. 安全边界

- 当前威胁模型采用 Nginx Basic Auth 与平台 Token 两层鉴权。
- 平台 Token 不进入前端构建产物、`localStorage` 或 `sessionStorage`；登录失败按客户端限速。
- 开发环境默认不开启 Basic Auth，生产部署示例保留配置入口。
- 平台 Token、Runner 密钥和数据库密码只通过环境变量提供。
- Runner 不获取数据库凭证；后端不执行用户脚本。
- 生产部署时应启用 HTTPS、请求限速和强随机凭证。
